# How to Run a Performance Review Cycle

**Product area:** Reviews  
**Audience:** Managers  
**Last updated:** September 2023

---

## Overview

Meridian HR allows managers to run structured performance reviews for their direct reports at any cadence. This article explains how to create a review cycle, assign participants, and collect responses.

---

## Step 1: Create a new review cycle

1. Navigate to **Reviews** in the left sidebar.
2. Click **New Review Cycle** in the top-right corner.
3. Enter a name for the cycle (e.g. "Q3 2023 Mid-Year Review").
4. Select a **review type**:
   - **Self + Manager**: Employees complete a self-assessment; managers complete a parallel assessment.
   - **360 Feedback**: Peers, direct reports, and managers all contribute ratings.
   - **Manager Only**: Only the line manager completes the review form.
5. Set a **due date**. Employees will receive automated reminders 7 days and 2 days before this date.
6. Click **Create Cycle**.

---

## Step 2: Add participants

After creating the cycle, you will be taken to the **Participants** tab.

- Click **Add Employees** to select individuals from your team.
- You can also click **Add All Direct Reports** to include everyone who reports to you.
- Each participant must have an assigned reviewer. By default, this is set to the participant's direct manager.

> **Note:** Participants added after the cycle has started will not receive retroactive reminders.

---

## Step 3: Customise the review form

Navigate to the **Form Builder** tab to edit the questions used in this cycle.

- Drag and drop question blocks to reorder them.
- Supported question types: Rating scale (1–5), Open text, Multiple choice, Goal alignment.
- You can import a question set from a previous cycle using **Copy from Cycle**.

---

## Step 4: Launch the cycle

When you are ready, click **Launch** on the cycle overview page. Participants will receive an email notification immediately.

Once launched, the cycle cannot be deleted. You can extend the due date but cannot change the question form.

---

## Step 5: Monitor completion

Use the **Progress** tab to see which employees have submitted and which are pending. You can send manual reminders by clicking **Nudge** next to any pending participant.

---

## Viewing results

Once the cycle closes, results are available in the **Insights Dashboard**. Managers can view aggregated scores and individual responses. Results are visible only to the reviewing manager and HR admins.

Calibration sessions can be scheduled directly from the Insights Dashboard. See the Calibration guide for more information.

---

## FAQs

**Can an employee see their own review results?**  
Yes. Managers control when results are shared with employees using the **Release Results** button in the cycle overview. Results are not visible to employees until released.

**What happens if a reviewer misses the deadline?**  
The cycle closes automatically on the due date. Late submissions are not accepted. You will need to create a new cycle to collect any missing responses.

**Can I run multiple cycles at the same time?**  
Yes. There is no limit on concurrent review cycles.

**How are ratings calculated in a 360 review?**  
Each rater's score is averaged equally. Manager ratings are not weighted differently from peer ratings unless Calibration Mode is enabled.
