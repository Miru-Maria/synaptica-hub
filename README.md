  ## Tech Stack

  - React 19 + TypeScript
  - Vite 7
  - Tailwind CSS v4 + shadcn/ui
  - Framer Motion
  - Lucide React

  ## Getting Started

  ```bash
  npm install
  npm run dev
  ```

  The dev server starts on port 5000 by default (set `PORT` to override).

  ## Build & Deploy

  ```bash
  npm run build   # outputs to dist/
  npm run preview # preview the production build locally
  ```

  For deployment, configure as a **Static** site with `publicDir = "dist"`.

  ## Import to Replit

  1. Go to [replit.com/new](https://replit.com/new) → **Import from GitHub**
  2. Select `Miru-Maria/synaptica-hub`
  3. After import, run `npm install` then `npm run dev`
  4. Deploy → Static → connect your custom domain
